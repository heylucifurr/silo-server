# TMDB logo

`tmdb-logo.svg` is TMDB's gradient wordmark, supplied by the fork owner. It
replaced TMDB's "alt short" lockup, which was downloaded unmodified from
<https://www.themoviedb.org/about/logos-attribution>.

It is TMDB's trademark, not Silo's, and is not covered by this repository's
license. Silo shows it next to TMDB scores, as TMDB's API terms of use allow.
Keep the file unmodified (colours, proportions) and less prominent than Silo's
own branding. TMDB asks clients to use a logo from its attribution page, so if
this lockup came from elsewhere, check it before shipping widely.
